Angel One SmartAPI credentials

Vercel (permanent) — Environment Variables

⚠️ Vercel pe file-save permanent nahi rehta (serverless). Isliye Vercel pe real data ke liye ye 4 variables Project → Settings → Environment Variables me daalo, phir Redeploy karo: 

SMARTAPI_KEY=<your api key>
SMARTAPI_CLIENT=<your client code>
SMARTAPI_PIN=<your mpin>
SMARTAPI_TOTP_SECRET=<your totp secret>
ADMIN_TOKEN=<koi bhi apna password>

Self-host (PC) pe: yahi form Save kar do — data/credentials.json me safe save ho jayega.
